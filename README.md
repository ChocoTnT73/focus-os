# FOCUS_OS

Single-file local productivity app. No backend, no accounts. All data in `localStorage`.

## Run
Open `index.html` in any modern browser.

## Features
- 5 tasks/day limit, Focus Mode (one task at a time), Empty State
- Daily + weekly habits, multi-intake supplements
- Long-term goals (max 5 active, up to 2 LEAD) + week goal
- State metrics 1–10 (custom, renameable)
- Mini calendar with day modal, week habits table
- Streaks, micro-rewards, anti-illusion overlay
- Pomodoro timer
- Local export/import JSON
